# 電子格子相関から見た分極雲の形成

Fröhlichの `output-n15-re800-g50` と `output-n15-re800-g300` を追加解析した。電子格子連結相関の実部について±rを平均し、各距離の600–700 fs平均値を基準に形成の進み具合を比較した。

## 分極雲の各成分は同時には育たない

時系列を20 fs幅の中央移動平均で平滑化し、その後の保存区間で再び閾値を下回らなくなる時刻を測った。閾値は各ケース・各距離の600–700 fs平均の50%または90%。したがって、共通の絶対振幅に到達する時間ではない。

| 距離 | γ=50: 50%時刻 (fs) | γ=300: 50%時刻 (fs) | γ=50: 90%時刻 (fs) | γ=300: 90%時刻 (fs) |
|---|---:|---:|---:|---:|
| r=0 | 78.5 | 35.5 | 463.0 | 316.5 |
| r=±1 | 169.0 | 35.0 | 508.5 | 329.0 |
| r=±2 | 328.5 | 213.0 | 611.0 | 541.0 |

γ=50では同一サイトの負相関が先に形成され、隣接・次隣接の負相関が遅れて育つ。γ=300では中心と隣接の形成が早く、次隣接にはなお遅れがある。少なくともこの初期状態からの形成過程では、γを大きくすると雲の形成は早まっている。

10/20/40 fsの平滑化幅で確認した50%時刻の範囲は、γ=50でr=0: 78–78.5 fs、r=1: 168.5–169.5 fs、r=2: 327.5–332.5 fs。γ=300ではr=0: 33.5–38.5 fs、r=1: 35–42 fs、r=2: 209–214 fs。この幅は解析条件への感度であり、計算精度や統計的信頼区間ではない。

局所分極が単一の固定形状の雲として一様に増幅されているわけではなく、周辺成分を含む相関分布が時間をかけて再編成されている。模型の浴はサイトごとに独立なので、この遅れを格子内の分極波の伝播速度と解釈することはできない。

## 終盤の形状と輸送の変化は大きさが異なる

600–700 fs平均では、γ=50→300により

- |C(0)|: 102.90→114.55 cm⁻¹（約11%増加）
- C(|r|=1)/C(0): 0.390→0.405
- C(|r|=2)/C(0): 0.083→0.105

となる。両ケースとも負相関がr=0,1,2に広がり、近距離の規格化形状は大枠で共通する。γ=300はその負相関が強く、より早く形成される。一方、D(600 fs)は86.12→43.42 a²/fsと約半分になる。電子格子相関の大きさや幅だけを使ってDの差を説明することはできない。

## 追従という解釈に対する意味

これらは局在・因子化初期状態からの**雲の形成と再編成**についての情報であり、移動中の電子に対する雲の追従遅れを直接測ったものではない。

前の応答で挙げた低周波位相遅れ `Γ/Ω₀²` は、Brownian浴をゆっくり駆動した場合の線形応答の指標である。自由振動の包絡時間 `2/Γ` とも、ここで測った非平衡な形成時刻とも異なる。今回の相関から「γ=300では雲ができるのが遅いからDが小さい」とは言えず、実際の形成は反対に早い。

700 fsまでの平衡化で両γが同程度に定常化したとは保証されない。γ依存性には、電流相関の時間発展の違いに加え、開始状態における電子と格子の相関の形成度合いが混ざっている可能性がある。平衡化を延長した複数の開始状態から電流相関を比較すれば、この寄与を切り分けられる。

追従そのものを見るには、移動方向を選んだ状態で電子を基準にした分極分布の前後非対称性、または二時刻の電子格子相関を測る必要がある。

## 再現

```bash
MPLCONFIGDIR=/tmp/ttdynamics-mplconfig python TTDynamics/examples/analysis_re800_gamma/analyze_cloud_formation.py
```

全閾値と平滑化幅依存性は [cloud_formation_metrics.csv](cloud_formation_metrics.csv)、図は [PNG](cloud_formation.png) / [PDF](cloud_formation.pdf)。基準の600–700 fs平均自体が厳密な平衡値ではないので、形成時刻は有限観測時間内の記述的な指標として扱う。
